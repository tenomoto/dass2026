Handson: equatorial ocean model

We learn the basics of data assimilation (DA) using an equatorial ocean model (Thacker and Long 1988).

Governing equations

The domain is one-dimensional in the longitudinal direction (\(x\)) with a cyclic boundary condition. The model consists of three linear waves. Each wave propagates with a constant wave speed; the model is linear of form.

\[ \frac{\partial q_j}{\partial t} + c_j\frac{\partial q_j}{\partial x} + \sigma q_j = d_j f,\; j = 0,\,2,\,4 \tag{1}\]

The index \(j = 0\) represents the Kelvin wave, which propagates eastward with the phase speed of \(c_0 = 1\) and the sensitivity to forcing of \(d_j = 1\). The indices \(j = 2, 4\) are the Rossby waves with \(c_2 = - c_0/3,\,c_4 = -c_0/7\) and \(d_2 = 1/2,\,d_4 = 1/8\), respectively. The damping coefficient \(\sigma\) is independent of the wave types.

The only observable is the sea-surface height.

\[ h = q_0 + q_2 - q_4 \tag{2}\]

Discretization

The governing equations (1) is discretized with the Lax-Wendroff method (Lax and Wendroff 1960). This scheme is a single step and explicit method of \(O(\tau^2)\), where \(\tau\) is the time step. The \(O(\tau)\) error in time is elimiated in space. Consider advection equation

\[ \frac{\partial q}{\partial t} + c\frac{\partial q}{\partial x} = 0, \tag{3}\]

which is discretized as

\[ \frac{q_j^{n+1} - q_j^n}{\tau} + c\frac{q_{j+1}^n - q_{j-1}^n}{2\Delta} = \frac{c^2\tau}{2}\left(\frac{q_{j+1}^n - 2q_j^n + q_{j-1}^n}{\Delta^2}\right) \tag{4}\]

where \(\Delta\) is the grid interval.

The right-hand side of (4) is a discretized form of the trunction error

\[ \frac{\tau}{2}\frac{\partial^2 q}{\partial t^2} = \frac{\tau}{2}\frac{\partial}{\partial t}\left(-c\frac{\partial q}{\partial x}\right) = \frac{c^2\tau}{2}\frac{\partial^2 q}{\partial x^2}. \]

Using the Lax-Wendroff method, (1) is discretized as

\[ q_{j, i}^n = \frac{1}{1 + \sigma \tau}\left\{ q_{j, i}^{n-1} + \frac{1}{2}\gamma_j(q_{j, i+1}^{n-1} - q_{j, i-1}^{n-1}) + \frac{1}{2}\gamma_j^2(q_{j,i+1}^{n-1} - 2q_{j,i}^{n-1} + q_{j, i-1}^{n-1}) + \tau d_j f_i^n \right\} \tag{5}\] where \(\gamma_j = c_j\tau/\Delta\).

Lagrangian method

For simplicity, it is assumed that observations are available on the model grid and observations are uncorrelated one another.

The cost function can be defined as

\[ J = \frac{1}{2} \sum_{i = 0}^{I} \sum_{n = 0}^N [(\eta_i^n - h_i^n)^2 + (\phi_i^n - f_i^n)^2] \tag{6}\]

where \(\eta_i^n, \phi_i^n\) are sea-surface height and wind stress observations and \(h_i^n = q_{0,i}^n + q_{2,i}^n - q_{4,i}^n, f_i^n\) are their model equivalents, respectively.

The Lagrangian function is defined as

\[ L = J + \sum_{j = 0}^{2, 4} \sum_{i = 0}^I \sum_{n=1}^N \lambda_{j, i}^n[ (1 + \sigma\tau)q_{j, i}^n - q_{j, i}^{n-1} + \frac{1}{2}\gamma_j(q_{j, i+1}^{n-1} - q_{j, i}^{n-1}) - \frac{1}{2}\gamma_j^2(q_{j,i+1}^{n-1} - 2q_{j, i}^{n-1} + q_{j, i-1}^{n-1}) - \tau d_j f_i^n] \tag{7}\]

Where \(\lambda_{j,i}^n\) is the Lagrange multiplier (and adjoint variable) with the terminal and initial conditions

\[ \begin{aligned} \lambda_{j,i}^{N+1} &= 0 \\ \lambda_{j,i}^0 &= 0. \end{aligned} \tag{8}\]

The terminal condition indicates at the future step \(n = N+1\), the adjoint is naught. The initial condition is fulfilled at the minimizer; it is the negative gradient, used for optimization.

\(\partial L/\partial \lambda_{j,i}^n\) recovers the forward model (5). \(\partial L/\partial q_{j,i}^n\) leads to the adjoint equation

\[ \lambda_{j, i}^n = \frac{1}{1 + \sigma \tau}\left\{ \lambda_{j, i}^{n+1} - \frac{1}{2}\gamma_j(\lambda_{j, i-1}^{n+1} - \lambda_{j, i+1}^{n+1}) + \frac{1}{2}\gamma_j^2(\lambda_{j,i-1}^{n+1} - 2\lambda_{j,i}^{n+1} + \lambda_{j, i+1}^{n+1}) + \varepsilon_j(\eta_i^n - q_{0,i}^n - q_{2,i}^n + q_{4,i}^n)\right\} \tag{9}\]

where \(\varepsilon_0 = \varepsilon_2 = 1, \varepsilon_4 = -1\). The last term on the right-hand side exist at the step where the observations are available. Finally, \(\partial L/\partial f_i\) gives \[ -\tau\sum_j d_j\lambda_{j,i}^n - (\phi_i^n - f_i^n) = 0 \tag{10}\] at the minimizer. The left-hand side of (10) represents the gradient with respect to forcing.

NoteExcercises for beginners
  • Write the forward model and run the model with a prescribed two-cycle forcing migrating with \(c_f = 0.5\).
  • Derive the adjoint model and estimate the initial state with the observations at \(n = 0. 16, 32\).
  • Compare the gradient descent and conjugate gradient methods.
  • Write an perturbed observation (PO) ensemble Kalman filter (EnKF) to assimilate observation sequentially.
  • Add noise to the observations.
  • Change the obsertion frequency and locations.
NoteExcercises for intermidates
  • Modify the variational method to estimate the forcing at all steps.
  • Write (ensemble) Kalman smoother and compare with the variational method.
  • Write a variational or ensemble data assimilation code for your favourite model, e.g. the Lorenz-96 model and its variants.
