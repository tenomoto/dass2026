Hand-son: Equatorial Ocean Model

We learn the basics of data assimilation (DA) using an equatorial ocean model (Thacker and Long 1988).

Governing equations

The domain is one-dimensional in the longitudinal direction (\(x\)) with a cyclic boundary condition. The model consists of three linear waves. Each wave propagates with a constant phase speed; the model is linear in form.

\[ \frac{\partial q_j}{\partial t} + c_j\frac{\partial q_j}{\partial x} + \sigma q_j = d_j f,\; j = 0,\,2,\,4 \tag{1}\]

The index \(j = 0\) represents the Kelvin wave, which propagates eastward with the phase speed of \(c_0 = 1\) and a sensitivity to forcing of \(d_0 = 1\). The indices \(j = 2, 4\) are the Rossby waves with speeds \(c_2 = - c_0/3,\,c_4 = -c_0/7\) and forcing sensitivities \(d_2 = 1/2,\,d_4 = 1/8\), respectively. The damping coefficient \(\sigma\) is independent of the wave type.

The only observable variable is the sea-surface height.

\[ h = q_0 + q_2 - q_4 \tag{2}\]

Discretization

The governing equations (1) are discretized with the Lax-Wendroff method (Lax and Wendroff 1960). This scheme is a single step explicit method of \(O(\tau^2)\), where \(\tau\) is the time step. The \(O(\tau)\) error in time is elimiated in space. Consider the advection equation

\[ \frac{\partial q}{\partial t} + c\frac{\partial q}{\partial x} = 0, \tag{3}\]

which is discretized as

\[ \frac{q_i^{n+1} - q_i^n}{\tau} + c\frac{q_{i+1}^n - q_{i-1}^n}{2\Delta} = \frac{c^2\tau}{2}\left(\frac{q_{i+1}^n - 2q_i^n + q_{i-1}^n}{\Delta^2}\right) \tag{4}\]

where \(i\) is the horizontal index and \(\Delta\) is the grid interval.

The right-hand side of (4) is a discretized form of the truncation error:

\[ \frac{\tau}{2}\frac{\partial^2 q}{\partial t^2} = \frac{\tau}{2}\frac{\partial}{\partial t}\left(-c\frac{\partial q}{\partial x}\right) = \frac{c^2\tau}{2}\frac{\partial^2 q}{\partial x^2}. \]

Using the Lax-Wendroff method, (1) is discretized as

\[ q_{j, i}^n = \frac{1}{1 + \sigma \tau}\left\{ q_{j, i}^{n-1} - \frac{1}{2}\gamma_j(q_{j, i+1}^{n-1} - q_{j, i-1}^{n-1}) + \frac{1}{2}\gamma_j^2(q_{j,i+1}^{n-1} - 2q_{j,i}^{n-1} + q_{j, i-1}^{n-1}) + \tau d_j f_i^n \right\} \tag{5}\] where \(\gamma_j = c_j\tau/\Delta\).

Lagrangian method

For simplicity, we assume that observations are available directly on the model grid and observation errors are uncorrelated with one another.

The cost function can be defined as

\[ J = \frac{1}{2} \sum_{i = 0}^{I} \sum_{n = 0}^N [(\eta_i^n - h_i^n)^2 + (\phi_i^n - f_i^n)^2] \tag{6}\]

where \(\eta_i^n, \phi_i^n\) are observations of sea-surface height and wind stress, respectively, while \(h_i^n = q_{0,i}^n + q_{2,i}^n - q_{4,i}^n, f_i^n\) are their model equivalents.

The Lagrangian function is defined as

\[ L = J + \sum_{j = 0}^{2, 4} \sum_{i = 0}^I \sum_{n=1}^N \lambda_{j, i}^n[ (1 + \sigma\tau)q_{j, i}^n - q_{j, i}^{n-1} + \frac{1}{2}\gamma_j(q_{j, i+1}^{n-1} - q_{j, i-1}^{n-1}) - \frac{1}{2}\gamma_j^2(q_{j,i+1}^{n-1} - 2q_{j, i}^{n-1} + q_{j, i-1}^{n-1}) - \tau d_j f_i^n] \tag{7}\]

where \(\lambda_{j,i}^n\) is the Lagrange multiplier (and adjoint variable). The minimum of \(J\) is found by the point where the gradients of \(L\) with respect to the state, multiplier, and forcing are identically zero.

The terminal and initial conditions of the adjoint variables are

\[ \begin{aligned} \lambda_{j,i}^{N+1} &= 0 \\ \lambda_{j,i}^0 &= 0. \end{aligned} \tag{8}\]

The terminal condition indicates that at the future step \(n = N+1\), the adjoint variable is zero. The initial condition is satisfied at the minimizer; it represents the negative gradient used for optimization.

\(\partial L/\partial \lambda_{j,i}^n\) recovers the forward model (5). \(\partial L/\partial q_{j,i}^n\) leads to the adjoint equation

\[ \lambda_{j, i}^n = \frac{1}{1 + \sigma \tau}\left\{ \lambda_{j, i}^{n+1} - \frac{1}{2}\gamma_j(\lambda_{j, i-1}^{n+1} - \lambda_{j, i+1}^{n+1}) + \frac{1}{2}\gamma_j^2(\lambda_{j,i-1}^{n+1} - 2\lambda_{j,i}^{n+1} + \lambda_{j, i+1}^{n+1}) + \varepsilon_j(\eta_i^n - q_{0,i}^n - q_{2,i}^n + q_{4,i}^n)\right\} \tag{9}\]

where \(\varepsilon_0 = \varepsilon_2 = 1, \varepsilon_4 = -1\). The last term on the right-hand side is present only at the step where observations are available.

Important
  • The adjoint equations (9) are derived simply by differentiating \(L\) (7) with respect to the state \(q_{j,i}^n\), without requiring the knowledge on adjoint operator.
  • The adjoint variables accumulate the misfit (innovation) between observations and the model equivalents, propagating them backward in time to the initial state.
  • The adjoint equations (9) are linear with respect to the adjoint variables.
Warning
  • Whether \(\lambda\) represents the gradient or the negative gradient depends on the sign preceding the multiplier, which is a matter of convention.
  • Note a minor but critical typo in (10d) of Thacker and Long (1988): The sign preceding \(\epsilon_j\) should be \(-\) rather than \(+\).

Finally, \(\partial L/\partial f_i\) yields

\[ -\tau\sum_j d_j\lambda_{j,i}^n - (\phi_i^n - f_i^n) = 0 \tag{10}\]

at the minimizer. The left-hand side of (10) represents the gradient of the cost function with respect to forcing.

Numerical optimization

The gradients are used to find the minimum of \(J\).

\[ \mathbf{x}_k = \mathbf{x}_{k - 1} + \alpha\mathbf{d} \tag{11}\]

where \(\mathbf{x}\) represents the control vector containing the variables to be optimized, \(\mathbf{d}\) is the descent direction, \(\alpha\) is the step size and \(k\) is the number of iteration.

The simplest approach is the gradient descent method

\[ \mathbf{x}_k = \mathbf{x}_{k - 1} - \alpha\mathbf{g} \tag{12}\]

where \(\mathbf{g}\) is the gradient vector (i.e., \(\mathbf{d} = -\mathbf{g}\)). Iterations are terminated based on convergence criteria such as the norm of the gradient, the cost function value or the relative change in cost from the previous step.

A more sophisticated approach is the conjugate gradient method, where the descent direction is updated by

\[ \mathbf{d}_k = -\mathbf{g}_{k-1} + \beta_k\mathbf{d}_{k-1}. \tag{13}\]

Several formulae exist to compute \(\beta_k\). Here, the Fletcher and Reeves (1964) formula is used:

\[ \beta_k = \frac{\mathbf{g}_k^\mathrm{T}\mathbf{g}_k}{\mathbf{g}_{k-1}^\mathrm{T}\mathbf{g}_{k-1}} \tag{14}\]

Ensemble Kalman filter

The ensemble Kalman filter (EnKF, Evensen 1994) approximates the forecast error covariance matrix using the sample covariance from an ensemble forecast:

\[ \mathbf{B} \approx \frac{1}{K - 1}\delta\mathbf{X}\delta\mathbf{X}^\mathrm{T} \tag{15}\]

where the \(k\)-th column of \(\delta\mathbf{X}\) is the ensemble perturbation \(\mathbf{x}_k - \bar{\mathbf{x}}\), \(K\) is the ensemble size and

\[ \bar{\mathbf{x}} = \frac{1}{K}\sum_{k=1}^K \mathbf{x}_k \tag{16}\]

is the ensemble mean.

The update equation for the ensemble mean is

\[ \bar{\mathbf{x}}^\mathrm{a} = \bar{\mathbf{x}}^\mathrm{f} + \mathbf{K}(\mathbf{y} - \mathbf{H}\bar{\mathbf{x}}^\mathrm{f}) \tag{17}\]

and for perturbations is

\[ \mathbf{x}^\mathrm{'a} = \mathbf{x}^\mathrm{'f} + \mathbf{K}(\mathbf{y}' - \mathbf{H}\mathbf{x}^\mathrm{'f}) \tag{18}\]

where \(\mathbf{H}\) is the linearized observation operator, \(\mathbf{K}\) is the Kalman gain matrix

\[ \mathbf{K} = \mathbf{BH}^\mathrm{T}(\mathbf{HBH}^\mathrm{T} + \mathbf{R})^{-1} \]

and \(\mathbf{R}\) is the observation error covariance matrix.

In (18), \(\mathbf{y}'\) is randomly drawn from the probability density distribution of the observation error, correspoinding to the perturbed observations (PO, Burgers et al. 1998; Houtekamer and Mitchell 1998).

Important
  • The EnKF does not require the adjoint equations (9).
  • The forecast error covariance matrix (15) is flow-dependent and can incorporate the ``the error of the day’’.
  • The error covariance matrix shrinks by \((\mathbf{I} - \mathbf{KH})\). If it shrinks too much, the true state may no longer lie within the space spanned by the ensemble. To prevent this the error covariance matrix is scaled up by a multiplicative factor (multiplicative inflation).
  • The ensemble size is typically much smaller than the state dimension (degrees of freedom), making the error covariance rank-deficient.
  • Localization is often required to reduce spurious correlations caused by sampling errors.
  • Several deterministic alternatives exist that does not perturb observations, thereby avoiding additional sampling noise
NoteExcercises for beginners
  • Write the forward model and run it with a prescribed two-cycle forcing migrating with \(c_f = 0.5\).
  • Derive the adjoint model and estimate the initial state with the observations at \(n = 0,\,16,\,32\).
  • Compare the performance of the gradient descent and conjugate gradient methods.
  • Implement a perturbed observation (PO) ensemble Kalman filter (EnKF) to assimilate observations sequentially.
  • Add noise to the synthetic observations.
  • Vary the observation frequency and locations.
NoteExcercises for intermediate users
  • Modify the variational assimilation scheme to estimate the forcing at across all time steps.
  • Implement (ensemble) Kalman smoother and compare its results with the variational approach.
  • Develop a variational or ensemble data assimilation code for a model of your choice (e.g. the Lorenz-96 model or its variants).
